### Failures found during implementation

- Zod refuses `.omit()` on a refined schema: split structural fields from author relational validation.
- Later URL refinements could throw before Zod emitted field paths: guard URL parsing.
- Draft scanning initially treated generic schema enum values as identities and rejected UI code: scan editorial/private values; separately verify exact projection structure and import provenance.
- Development exposed raw author files before the SSR fallback: add a pre-Vite filesystem boundary and generated-media handler.
- Fixture Vite caches shared the dependency junction and caused dev reloads: use workspace-local cache plus explicit entry scanning; both retained-DOM development regressions now pass.
- An image failure before React hydration was missed by `onError`: inspect completed image state on attachment as well as handling later errors.
- ES2023 `toSorted` exceeded the accepted ES2022 library target: sort the newly filtered copy; a selector regression proves input order remains unchanged.
- The original artifact scanner could both miss nested private text and reject legitimate UI matches: replace it with a public-only reference build.
- Header-only image parsing accepted malformed media: require complete container structure and an actual browser decode.
- Test-only inherited `NODE_ENV` changed production fixture output: force production mode for fixture builds; correct the synthetic PNG checksum.
